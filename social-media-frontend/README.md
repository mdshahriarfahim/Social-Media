# Khata — Social Feed Frontend (React)

Login/Register ছাড়া একটা সোশ্যাল ফিড + Real-time মেসেজিং frontend, যেটা আগে বানানো Express/MongoDB backend-এর সাথে কথা বলে।

## Folder Structure
```
src/
├── api.js                 # Backend এর সাথে REST কল করার helper
├── socket.js               # Socket.io client (real-time মেসেজিং)
├── App.jsx                 # মূল লেআউট (Sidebar + Feed/Messages সুইচ করা)
├── main.jsx                 # React entry point
├── index.css                 # ডিজাইন টোকেন ও স্টাইল
└── components/
    ├── Sidebar.jsx          # বাম পাশের নেভিগেশন + username ইনপুট
    ├── UsernameGate.jsx     # প্রথমবার খুললে নাম জিজ্ঞেস করার স্ক্রিন
    ├── Feed.jsx             # পোস্ট composer + পোস্ট লিস্ট
    ├── PostCard.jsx         # একটা পোস্ট (লাইক, কমেন্ট)
    └── Messages.jsx         # কথোপকথন লিস্ট + real-time চ্যাট
```

## চালানোর আগে
Backend (social-media প্রজেক্ট) আগে থেকে `http://localhost:3000`-এ চালু থাকতে হবে, MongoDB সহ। Backend-এ নতুন করে `cors` প্যাকেজ লাগবে:
```bash
npm install cors
```
(এটা আগের `index.js`-এ যোগ করা হয়েছে, তাই backend ফাইলগুলো আবার ডাউনলোড করে নিন।)

## এই frontend চালানোর নিয়ম
```bash
npm install
npm run dev
```
এরপর ব্রাউজারে খুলুন: `http://localhost:5173`

## কীভাবে কাজ করে
- প্রথমবার খুললে নাম জিজ্ঞেস করবে (কোনো password লাগবে না) — নামটা ব্রাউজারের localStorage-এ সেভ থাকবে, তাই পরের বার রিফ্রেশ করলে আবার জিজ্ঞেস করবে না।
- **ফিড ট্যাব:** পোস্ট লেখা, লাইক দেওয়া/তোলা, কমেন্ট করা — সব backend-এর REST API কল করে।
- **মেসেজ ট্যাব:** বামে ইনবক্স (কার সাথে শেষ কথা হয়েছে), ডানে চ্যাট। নতুন username লিখে নতুন কথোপকথন শুরু করা যায়। Socket.io দিয়ে দুইজন একসাথে ব্রাউজারে খোলা থাকলে মেসেজ রিফ্রেশ ছাড়াই আসবে।

## টেস্ট করার সহজ উপায়
দুইটা আলাদা ব্রাউজার ট্যাব/উইন্ডো খুলুন (একটা normal, একটা incognito) — একটাতে `karim` নাম দিন, আরেকটাতে `rahim`। এবার মেসেজ ট্যাব থেকে একে অপরকে মেসেজ পাঠিয়ে দেখুন, রিফ্রেশ ছাড়াই আসছে কিনা।

## ডিজাইন কনসেপ্ট
"Khata" (খাতা/নোটবুক) থিমে বানানো — উষ্ণ প্যাপার-রঙা ব্যাকগ্রাউন্ড, গাঢ় সবুজ কালির অ্যাকসেন্ট রঙ, আর পোস্টগুলো ইনডেক্স-কার্ডের মতো দেখতে, যাতে এটাকে সাধারণ টেমপ্লেটেড SaaS ডিজাইনের বদলে একটা ব্যক্তিগত নোটবুক/বোর্ডের মতো লাগে।
